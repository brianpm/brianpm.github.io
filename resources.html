Resources

A centralized collection of useful links and tools for climate science research.

Global Temperature

Interactive Browser

Annual global mean surface temperature anomalies from five major datasets (HadCRUT5, GISTEMP, Berkeley Earth, NOAAGlobalTemp, ERA5), with uncertainty estimates.

Climate Trends

Interactive Browser

Ocean heat content, Earth energy imbalance, and total solar irradiance — long-term records of the planetary energy budget from NOAA, NASA, and NCEI.

Sea Ice Extent

Interactive Browser

Interactive chart of Northern Hemisphere sea ice extent from 1978 to present, using daily satellite data from NSIDC.

NOAA CO₂ Data

Interactive Browser

Browse and visualize atmospheric CO₂ measurements from NOAA monitoring stations around the world. Interactive charts powered by Plotly.

Forecast Accuracy

Rolling 14-Day RMSE

Rolling 14-day RMSE for next-day high temperature forecasts across 60+ US cities, comparing NBM, GEFS, NDFD, ECMWF, and UKMO. Updated daily.

Boulder Climate

Local Weather Station

Daily weather records from a personal station in northeast Boulder, CO (2015–present). Interactive charts of temperature and humidity, a polar annual cycle view, and all-time extreme-day records.

Publications

Research Output

Full list of peer-reviewed publications and scientific contributions. Includes journal articles with DOI links for direct access.

GitHub

Code & Projects

Open-source code, analysis scripts, and research tools. Includes climate model diagnostics and data visualization utilities.

Community Models

CESM & Atmosphere Model

The Community Earth System Model (CESM) and Community Atmosphere Model — the primary models used in this research.

Simpler Models

Model Hierarchy

A hierarchy of model complexity within CESM for targeted process studies and understanding climate system behavior.

Jupyter on CGD Systems

Setup Guide

How to run JupyterLab on a CGD server and connect to it from a local browser using an SSH tunnel.

Fish Shell Tips

Shell Tips

Useful tips for the fish shell, including PATH management with fish_user_paths and fish_add_path.

citation-import

Utility / macOS Tool

Watches ~/Downloads and automatically imports BibTeX, RIS, and EndNote reference files into a master .bib bibliography. Generates BibDesk-style citation keys and checks for duplicates.
